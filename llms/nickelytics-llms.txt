# Nickelytics (R-Ads by Robot.com)

> Nickelytics is an out-of-home (OOH) and digital-out-of-home (DOOH) advertising
> platform that turns moving assets — rideshare and gig-economy vehicle wraps,
> autonomous sidewalk delivery robots and e-scooters — into measurable media,
> with geo-targeting, route verification, proof-of-play and campaign reporting.
> Nickelytics was acquired by Kiwibot in September 2024; Kiwibot rebranded to
> Robot.com in 2025 and the product now ships as R-Ads, a self-serve suite for
> robot media (RDOOH), vehicle wraps (MOOH) and digital screens (DOOH).

## What an agent can actually call

Nickelytics publishes **no developer portal, no API reference, no SDKs and no
MCP server**. One machine-readable contract is served publicly: the platform
authentication API, a Better Auth instance whose OpenAPI 3.1.1 document is
returned by `/api/auth/open-api/generate-schema` on both API hosts. The
advertising product surface at `https://api.nickelytics.com/v1` is
authenticated (`401 Authorization header required`) and undocumented — campaigns
are bought through the R-Ads Ad Manager UI, not an API.

- Auth API base: https://api-ads.robot.com/api/auth
- Auth API base (legacy host, same load balancer): https://api.nickelytics.com/api/auth
- OpenAPI: https://api-ads.robot.com/api/auth/open-api/generate-schema
- JWKS: https://api-ads.robot.com/api/auth/.well-known/jwks.json (EdDSA / Ed25519)
- Auth: `Authorization: Bearer <token>` or the `apiKeyCookie` session cookie
- Errors: `{"message": "..."}` — not RFC 9457
- Rate limits: 429 declared on every operation; no numbers and no headers published
- Idempotency: not supported

## APIs

- [Nickelytics R-Ads Platform Authentication API](https://www.robot.com/r-advertising): sign-in, sessions, account linking, JWT/JWKS, organizations, teams, invitations, SAML SSO, admin user management and audit events — 151 operations.
